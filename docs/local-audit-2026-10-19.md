## Consequences for the first cut

The source record should be reconciled with these findings before pairing. In particular, don't train the stale “unmerged fix” or “no companion receipts” statements as present facts, don't promote stub receipts into scored model evidence, and don't turn unjudged historical gate decisions into truth labels.

The first runnable work here is the evaluator, not model selection. The release filter, real source corpus, Ground query, old judged labels, Studio version check, independent baseline reproduction, and Jetson load cycle still prevent an honest P0 exit. See [the phase checklist](p0-checklist.md).
